# Contributing

Thanks for helping. Small, focused pull requests are easiest to review.

## Good first contributions

- A new transition in `src/primitives/Wipes.tsx`
- A new feel in `src/brands/spec.ts` (easing + timings), with its sound set in `scripts/make-sounds.mjs`
- An example brand in `brands/example-<name>/` (made-up brands only, no real logos)
- Fixes for text that overflows in one of the formats

## Rules of thumb

1. **Tokens, not values.** Colours, fonts, easing and durations come from
   `useBrand()`, and sizes come from `useLayout()`. A primitive should never hard-code a
   brand colour.
2. **Every format.** Check your change in 16:9 and 9:16 at least
   (`npm run studio`, then switch folders in the sidebar).
3. **Only assets you can give away.** No samples, fonts or images unless
   they're CC0 or generated by code in this repo.
4. Run `npm run typecheck` before opening a pull request.

## Reporting a bug

Open an issue with your `brand.json`, the format, and a screenshot or a short
clip of the problem.
